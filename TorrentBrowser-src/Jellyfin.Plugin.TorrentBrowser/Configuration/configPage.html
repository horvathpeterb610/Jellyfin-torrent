Indexer

The host and indexer id from Prowlarr, like http://localhost:9696/1 — leave off the /api, the plugin adds it. Find the id by clicking the indexer name in Prowlarr.
In Prowlarr, under Settings then General.
Tests run against saved settings, so save your changes first.


Torrent client

Only qBittorrent is implemented so far.
Leave empty to use the client's own default. This path is resolved by the torrent client, so it must make sense on that machine, not on Jellyfin's. Point it inside a folder Jellyfin scans or finished downloads will not appear in your library.


Access

Turn this off and every signed-in user can add downloads to your client.
